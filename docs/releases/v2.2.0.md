# Qwen Studio 2.2.0

## 中文

- Mac 和 Windows 新增应用内环境检测：缺少 Python 时也能打开检测页；Windows 缺少 WebView2 时使用原生备用页面。
- 逐项显示检测结果，通过显示 🎉；必需项通过后才能进入。支持安装或修复 Python 依赖、重新检测和查看安装日志。
- 补齐中文、英文及跟随系统，覆盖设置、下载、任务、错误、预览和原生菜单，选择可持久保存。用户内容不参与翻译。
- 依赖缺失或本地服务退出后返回检测页。Ollama 为可选检查项，图像权重仍在主界面下载。

另新增官方生图/改图提示词增强，默认 2K、精确文案、自动比例、圈选涂抹与蒙版、反向提示词及批量结果。每个增强模型约 18.84 GB，需单独下载。[能力与限制](https://github.com/rigorhormist/QwenStudio/blob/v2.2.0/docs/generation.zh-CN.md)。

更新时保留原数据目录和 Windows 的 `.venv`、`settings.local.json`。首次打开新版会重新检测环境。

## English

- Added in-app environment checks on Mac and Windows, including a native Windows fallback when WebView2 is unavailable. Python is not needed to open the check screen.
- Passed checks display 🎉. All required checks must pass before entry. Install or repair Python dependencies, retry checks and read installation logs inside the app.
- Completed Chinese, English and system-language support across settings, downloads, tasks, errors, previews and native menus. Language persists; user content is not translated.
- Missing dependencies and stopped local services return to the check screen. Ollama is optional; image weights are still downloaded inside the main app.

Also added both official prompt enhancers, a 2K default, exact lettering, automatic ratios, annotations/masks, negative prompts and serial batches. Each enhancer needs a separate download of about 18.84 GB. [Capabilities and limits](https://github.com/rigorhormist/QwenStudio/blob/v2.2.0/docs/generation.en.md).

Keep existing data and Windows `.venv` / `settings.local.json` when updating. The new version checks the environment on first launch.

## Validation / 检查范围

Backend tests cover missing imports, timeouts, optional Ollama, preference persistence, downloads and queues. Localization checks cover catalog completeness, language switching, dynamic text and preservation of user content. The Mac bootstrap was checked with missing and working Python environments; the real MPS preflight passed without loading model weights. Both desktop shells build. Windows NVIDIA image generation was not run on this Mac. Enhancer weights were not downloaded or run; actual PE output quality is unverified.

后端、翻译、双平台编译及 Mac 原生首次启动流程已检查；未在本机执行 Windows NVIDIA 图像推理，也未为此次更新生成测试图片。PE 权重未下载和运行，实际增强效果尚未验证。

Packages exclude Python, model weights and Ollama. Windows includes the .NET runtime. Mac uses an ad-hoc signature and is not notarized. / 发布包不含 Python、模型权重和 Ollama；Windows 自带 .NET，Mac 为临时签名且未公证。
