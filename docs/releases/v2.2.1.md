# Qwen Studio 2.2.1

## 中文

修复 Windows 下载版漏查系统 Python 的问题。2.2.0 只检查应用目录中的 `.venv` 或手动指定的环境，因此已有环境的移动硬盘版本能通过，新解压的版本却可能报告未安装 Python。

- 自动查找 Python Launcher、安装登记和 PATH 中的可用解释器，并显示实际路径。
- 分别提示解释器版本不兼容、32 位 Python 和缺少依赖；跳过会打开 Microsoft Store 的占位程序。
- 检测与依赖安装使用同一套查找逻辑。已有完整系统环境可直接使用，修复仍在应用环境内安装依赖。

完整解压新版后打开 `start.cmd`。如果只有 PyTorch、Diffusers 等依赖未通过，点“安装或修复依赖”。更新时保留 `.venv`、`settings.local.json` 和原数据目录。Mac 功能保持不变。

## English

Fixed system Python discovery in the Windows download. Version 2.2.0 only checked the app's `.venv` or an explicit override, so an existing configured folder could pass while a fresh extraction reported missing Python.

- Find working interpreters through Python Launcher, installation registrations and PATH; show the selected path.
- Distinguish unsupported versions, 32-bit Python and missing dependencies. Skip Microsoft Store placeholder executables.
- Use the same discovery for checks and dependency setup. Complete system environments can be used directly; repairs install into the app environment.

Extract the entire package and open `start.cmd`. If only dependencies such as PyTorch or Diffusers fail, choose Install or repair dependencies. Preserve `.venv`, `settings.local.json` and existing data when updating. Mac functionality is unchanged.

Windows checks cover an existing virtual environment, a fresh folder without one, an installation registered outside PATH, explicit overrides and incompatible interpreters. No model weights or image generation are involved. / Windows 检查覆盖上述识别场景，不下载模型、不执行生图。
