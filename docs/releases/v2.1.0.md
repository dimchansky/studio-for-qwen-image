# Qwen Studio 2.1.0

Qwen Studio 是为解决 Ollama 等平台暂不支持 Qwen Image 2.1 情况的替代交流平台。本次发布同时提供 Mac 与 Windows 源码、桌面程序和中英文文档。

## 下载 / Downloads

- `QwenStudio-2.1.0-windows-x64.zip`：完整解压，先运行 `setup.cmd`，再运行 `start.cmd`。
- `QwenStudio-2.1.0-macos-arm64.zip`：解压后运行 `setup.command`，再打开 `Qwen Studio.app`。
- `QwenStudio-2.1.0-source.zip`：双平台源码及文档。
- `SHA256SUMS.txt`：下载包校验值。

Python、Ollama 和约 33.1 GB 的图像模型需要单独安装或下载。Windows 包包含 .NET 运行时，另需 WebView2；Mac 包适用于 Apple Silicon。桌面包未作开发者证书签名或 Apple 公证。

Install Python first. Platform archives include compiled desktop shells but exclude Python dependencies and model weights. Run the included setup script before launch. Image weights are downloaded from your chosen source inside the app. Ollama is a separate prerequisite for text chat.

## 本次变化 / Changes

首次下载可选择 ModelScope 或 Hugging Face，并显示实时速度。任务栏增加展开和收起动画，停止操作使用红字。会话输入框略微增高，预览按原比例显示，避免被底部工具区域截断。两端都已集成黑色 Q 图标。

Both platforms include model-source selection, download speed, animated task trays, red stop controls, adjusted composer height and uncropped previews. The shared black Q icon is included in the native applications.

## 验证范围 / Validation scope

本地完成双平台后端回归检查、界面交互检查、Windows x64 交叉编译、Mac arm64 编译和签名完整性检查。此次发布准备未运行新的 GPU 生图基准；Windows 原生窗口和 NVIDIA 推理、不同设备的 2K 生成表现仍需实机反馈。

Local checks cover backend regressions, shared UI interactions, a Windows x64 cross-build, a Mac arm64 build and signature integrity. No new GPU image benchmark was run for this release. Native Windows behavior, NVIDIA inference and 2K completion across devices need hardware testing.
