# 使用说明

[English](usage.en.md) | [首页](../README.md)

## 生图与改图

新会话可选择“图像”或“对话”。进入已有会话后，输入框会缩小，模式选项收进加号菜单。加号菜单还可以添加参考图、打开图片库和调整参数。

输入画面描述后点击发送，或按 `⌘ Enter`（Mac）/ `Ctrl Enter`（Windows）。任务可以排队；停止按钮只取消选定任务。生成结果可以点开大图，选择原始尺寸或保存。点“继续修改”会将图片加入当前输入框。

预览会在部分推理步骤更新，中间画面可能与最终结果不同。预览保持原始比例，任务栏不遮挡输入框；可随时向上滚动查看历史。

## 参数

| 参数 | 含义 |
| --- | --- |
| 尺寸 | 输出画面的宽和高。2K 预设采用官方公布的比例尺寸，但内存需求显著增加 |
| 步数 | 去噪迭代次数，应用允许 1–60，默认 40。少步数适合尝试构图 |
| 种子 | `-1` 每次随机；非负整数固定初始噪声，便于比较提示词修改 |
| 透明背景 | 向模型提示词加入官方建议的 RGBA 请求，最终透明度仍取决于模型输出 |
| 思考强度 | 用于支持思考的 Ollama 聊天模型，与图像步数无关 |

相同种子不保证在不同设备、依赖版本或不同图片尺寸下逐像素相同。当前图片上传会缩放到最长边 2048；单图超过 2500 万像素会被拒绝。

## 普通聊天

先启动本机 Ollama 并下载聊天模型。模型列表来自 Ollama；嵌入、OCR 和云端名称的模型不会进入当前聊天列表。若模型声明支持思考，应用显示相应选项：gpt-oss 系列显示轻度、标准、深入，其他支持模型可能提供开关。

聊天助手可以帮助编写提示词，但不会自动调用图像工具。需要出图时切换图像模式发送。当前聊天内容以纯文本呈现。

## 常见问题

### 页面说模型未就绪

在模型设置检查下载进度和模型目录。首次下载需要选择来源。若下载已中断，再次点击下载可继续；错误详情在数据目录的 `download.log`。不要把其他版本权重与当前目录混放。

### 生成提示内存不足

关闭占用大量内存的应用，降低尺寸到 512 或 768，再重试。降低尺寸通常比只减少步数更能减少峰值内存。2K 是可选择的输出规格，实际是否完成取决于硬件和任务。

### 图片有色带、接缝或脏污

确认使用最新版本及其固定依赖。应用以 FP32 完整解码，并关闭 VAE 分块；这些设置处理解码造成的伪影。它们无法保证模型生成内容本身没有瑕疵。报告问题时提供尺寸、步数、种子和脱敏后的示例图片。

### Windows 无法打开或没有 GPU

确认运行过 `setup.cmd`，WebView2 已安装，`.venv` 和 `app` 与 `backend` 保持同级。检查 `desktop.log`。安装脚本末尾会打印 `CUDA available`，为 False 时检查 NVIDIA 驱动和 PyTorch CUDA 构建是否匹配。

### Mac 无法启动 Python

重新运行 `setup.command`，确认原 Python 安装仍然存在。虚拟环境依赖用于创建它的 Python，移除或更换 Python 后需要重建运行环境。错误记录在数据目录的 `app.log`。

### 分享诊断信息

提交 Issue 时说明系统版本、GPU/统一内存、应用版本、重现步骤和错误信息。日志和 Windows 导出的 PNG 元数据可能包含提示词；旧版本日志或图片元数据也可能包含本地路径。公开前请自行检查。
